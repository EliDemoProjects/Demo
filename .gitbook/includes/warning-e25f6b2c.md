{% hint style="warning" %}
For accounts with 2FA activated, Checkmarx enforces this when running SCA Resolver and plugins causing the integrations to fail. Therefore, an account admin needs to enable a 2FA exemption for each user that sets up SCA Resolver and plugin integrations. For more information, see [Enabling Two-Factor Authentication Exemptions](../../untitled/.gitbook/includes/user-accounts.md#UUID-6ed0dd67-c2c8-b879-43f6-4f637376f9a2).
{% endhint %}
