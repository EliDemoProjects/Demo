# Checkmarx SCA Extension for Visual Studio Code

{% hint style="warning" %}
The standalone SCA extension for VS Code is no longer supported. The SCA Scanning tool is now bundled together with the Checkmarx One extension and the KICS Auto Scanning tool. The SCA Scanning tool is still a free tool that is available for all VS Code users. Documentation for the SCA Scanning tool is now available [here](/document/preview/152197#UUID-b2d3eacd-9ddc-854f-6a5e-2d34b2b869d7).
{% endhint %}
