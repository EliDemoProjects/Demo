# Managing My Profile

Each user is able to edit their own profile info. They can also change their password.

{% hint style="info" icon="pencil" %}
Admin users can edit the user account info and reset passwords for all users in the organization, see [Editing a User Account](user-accounts.md#UUID-2fc8e8ce-43af-b128-0f66-b182bb46340f) .
{% endhint %}

**To edit your profile details:**

1. In the main navigation, click **User Management**.

   The Access Control screen opens in a new tab.
2. On the Access Control screen select the **My Profile** tab.
3. On the **General** tab (default), edit the desired fields.

   {% hint style="info" icon="pencil" %}
   The *Username, Teams* and *Authentication Provider* fields cannot be edited.
   {% endhint %}
4. Click **Save.**

   The edited user info is saved.
5. If you would like to change your password, click on the **Password** tab and do the following:

   1. Enter your **Current Password**.
   2. Enter your **New Password**.

      {% hint style="info" icon="pencil" %}
      The password must contain at least 8 characters, including at least one special symbol, one lower case letter, and one upper case letter.
      {% endhint %}
   3. Click **Update Password**.

      The new password is saved.
